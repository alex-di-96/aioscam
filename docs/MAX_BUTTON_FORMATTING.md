## Результаты

### ТЕСТ 1: HTML форматирование
**Статус:** ✅ Работает

HTML теги отображаются корректно:
- `<b>жирный</b>` → **жирный**
- `<i>курсив</i>` → *курсив*
- `<code>код</code>` → `код`
- `<a href='...'>ссылка</a>` → [ссылка](...)

**Примечание:** Форматирование применяется через `format=ParseMode.HTML`

---

### ТЕСТ 2: Markdown форматирование
**Статус:** ❌ НЕ работает

Markdown синтаксис отображается как обычный текст:
- `**жирный**` → отображается как `**жирный**` (не форматируется)
- `*курсив*` → отображается как `*курсив*` (не форматируется)
- `` `код` `` → отображается как `` `код` `` (не форматируется)
- `[ссылка](...)` → отображается как `[ссылка](...)` (не форматируется)

**Вывод:** Max Messenger НЕ поддерживает Markdown форматирование, только HTML.

---

### ТЕСТ 3: Многострочные кнопки
**Статус:** ❌ НЕ работает

Кнопки с символами `\n` не отображаются как многострочные:
- Текст кнопки обрезается
- Длинные кнопки (125+ символов) заканчиваются "..."
- Символы `\n` игнорируются или обрезаются

**Пример:**
```
Текст: "Первая строка\nВторая строка\nТретья строка"
Отображение: "Первая строка..." (обрезано)
```

**Вывод:** Max Messenger НЕ поддерживает многострочные кнопки. Для отображения длинного текста используйте:
1. Короткие названия кнопок (до 30-40 символов)
2. Подробности в тексте сообщения, а не в кнопке
3. Разбивайте информацию на несколько коротких кнопок вместо одной длинной

---

## Рекомендации для ToirBot

1. **Используйте HTML форматирование** для сообщений (не Markdown)
2. **Кнопки должны быть короткими** (максимум 30-40 символов для читаемости)
3. **Не используйте \n в кнопках** - они обрезаются
4. **Длинную информацию размещайте в тексте сообщения**, а не в кнопках
5. **Разбивайте длинные действия на несколько кнопок** вместо одной длинной

## Примеры

### ✅ Хорошо
```python
# Короткая кнопка + подробности в сообщении
builder.callback("📋 Подробнее", "show_details")
await event.answer(
    "<b>Детальная информация</b>\n\n"
    "Здесь можно разместить длинный текст с подробностями...",
    format=ParseMode.HTML
)
```

### ❌ Плохо
```python
# Длинная кнопка (обрежется)
builder.callback("📋 Очень длинная кнопка с кучей информации которая обрежется", "show_details")

# Многострочная кнопка (не работает)
builder.callback("Первая строка\nВторая строка", "show_details")

# Markdown форматирование (не работает)
await event.answer("**Жирный текст**", format=ParseMode.MARKDOWN)
```
